# Electric Vehicle Performance Analysis using PCA

This project explores electric vehicle performance data using Principal Component Analysis (PCA).

## Methods
- Principal Component Analysis (PCA)
- Data visualization
- Exploratory data analysis

## Tools
- R
- ggplot2
- dplyr

## Output
The analysis identifies key dimensions affecting EV performance such as battery capacity, range, and efficiency.
